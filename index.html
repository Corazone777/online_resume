the product

Atlas — a game engine that lives in the browser.

A browser-based 3D editor: write code against a live Babylon.js scene, manipulate meshes with gizmos, manage the scene graph, import .glb models, and export a playable game — no install, no plugins. Served by a Go backend. Try the panels below — they're interactive.
