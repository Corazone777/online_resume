the product

Atlas — a game engine that lives in the browser.

A browser-based 3D editor: write code against a live scene, manipulate meshes, import .glb models, and export a playable game — served by a Go backend. Here's the idea in miniature — edit the code, then drag the box or tweak it from the inspector.

CI/CD

Push to deploy: the pipeline builds the image, ships it to the registry, and rolls it out — no manual steps.

Infrastructure as code

The server is codified in Ansible; the box itself defined in Terraform — reproducible from scratch.

Observability

Prometheus + Grafana with host, uptime, and TLS-expiry metrics — health at a glance.

Networking & security

Hardened nginx, a firewall, and a hand-configured WireGuard VPN for private dashboard access.
