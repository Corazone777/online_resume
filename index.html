the product

Atlas — a game engine that lives in the browser.

Atlas is a browser-based 3D game editor. You build scenes, program game logic, import assets, and export a playable game — all in the browser, rendered in real time with Babylon.js and served by a Go backend. No install, no plugins.

CI/CD

Push to deploy: pipeline builds the image, ships it to the registry, and rolls it out over SSH — no manual steps.

Infrastructure as code

The server is fully codified in Ansible; the box itself is defined in Terraform — reproducible from scratch.

Observability

Prometheus + Grafana with host, uptime, and TLS-expiry metrics — I can see the system's health at a glance.

Networking & security

Hardened nginx, a firewall, and a hand-configured WireGuard VPN for private access to internal dashboards.
